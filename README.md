# 🚀 Voidbreaker (Beta)

Voidbreaker adalah game 2D space shooter berbasis HTML5 Canvas.

## 🎮 Features (Beta)
- Stage 1: Enemy wave + Boss battle (multi-phase)
- Stage 2: Survival mode (90 seconds)
- Power-ups: Rapid Fire, Double Shot, Shield
- Laser enemy (Stage 2)
- Boss laser phase
- Keyboard & Mobile Touch Control
- Shield visual & effects
- Local high score (localStorage)

## 🕹 Controls
### Desktop
- Move: WASD / Arrow Keys
- Shoot: Space
- Restart: R
- Mute: M

### Mobile
- Drag: Move ship
- Tap: Shoot

## ⚠️ Beta Notes
- Difficulty & laser pacing not final
- Visual polish ongoing
- Balancing will be adjusted post-beta

## 📦 Tech Stack
